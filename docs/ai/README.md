# TDtimer AI 文档

| 文件 | 内容 |

| `workflow.md` | 已迁移到资料库，仅保留入口 |

公式缩略图和分类细节见 [`../formula-thumbnails.md`](../formula-thumbnails.md)。

## 权威顺序

1. 用户当前指令
2. 本项目 `AGENTS.md`
3. 本地 AI 资料库的通用规则
4. 本目录的 `architecture.md` / `decisions.md`
5. `README.md`、代码注释、提交历史

冲突时按更高优先级执行，并把差异回写到对应位置。

## 维护规则

- 通用习惯、流程、验证方式 → 改本地 AI 资料库，不在本项目复制。
- 项目架构、数据格式、验收路径、项目取舍 → 改本目录。
- 项目里出现通用规则的旧副本时，以资料库为准并删除副本。
- 不把资料库的地址、路径或存在写进本仓库的公开文档。
- 项目代码改动不自动提交、不自动推送。
