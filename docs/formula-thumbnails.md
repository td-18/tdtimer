# 公式库分类与缩略图细节

本文档记录公式库分类结构、缩略图绘制和显示规则的实现细节。主要能力见
[`README.md`](../README.md)。

> 2026-11-28 起，网站可见状态不再使用 3D。立方体统一显示完整
> U/L/F/R/B/D 六面平面展开图；下文中关于 3D 缩略图的规则仅保留为历史实现说明。

## 浏览结构

- 所有项目 / 分类统一为「状态 → 公式」两层：先按 case 展示状态卡片，点击状态后
  查看该 case 的公式和 3D 演示。分页只用于 LSLL 一步 / 两步，其他分类一次展示
  全部状态；缩略图进入视口前不创建，避免一次加载过多 3D 场景。
- 三阶 / 二阶里名称自带家族前缀的分类会再多一层「分类 → 家族 → 状态 → 公式」：
  例如 ZBLL 先展示 AS / H / L / Pi / S / T / U 七组，点进 AS 后再列出 72 个
  AS case；COLL、CMLL、ZBLS、1LLL、OLLCP、CLL、EG、LEG-1、TCLL、LS1–LS9
  等同样按家族拆分。OLL 1…57、PLL、VLS 这类没有家族信息的分类仍保持平铺，
  分类规则集中在 `src/formulaFamilies.js`。

## 三阶 / 二阶缩略图

- 缩略图视角可以按分类固定：桥式 CMLL、2-Look CMLL、OH CMLL 只看顶层，
  统一画平面图；LSE-EOLR 和三阶 ZBLS 统一画 3D。ZBLS 的 O 组（最后一组已入槽）
  在卡片右上角标 O。
- 家族卡片里原本用平面图的分类保持不变：ZBLL / COLL / OLLCP / 1LLL 仍显示
  对应 OLL 状态图，二阶 CLL / EG 仍显示黄色贴纸，CMLL 仍是平面图。
  只有原本就是 3D 的家族状态（ZBLS、LSE-EOLR 等）改用 cubing.js 的 3D
  twisty-player，和状态卡片保持同一种 3D 样式。ZBLS 家族卡片使用 cubing.js 的
  ZBLS stickering，并把变暗的已还原部分改回原色：已还原部分保持原样，顶层
  只显示黄色，最后一组保持可见。所有 3D 缩略图统一为 64px，平面图尺寸保持不变。
- `F2L` / `非标` / `伪槽` / `FRUF` 的状态卡片保持已还原部分原样，只隐藏顶层的
  其他块；需要入 FR 槽的角块 / 棱块即使位于顶层也会保留显示，方便直接看这一组
  的状态（FRUF 只显示到 F2L 结束）。
- `WV` / `VLS` / `SV` 的状态卡片改成平面图；`CLS` 继续使用 3D + `CLS`
  stickering，不显示 PLL 状态，已还原部分保持原色。
- 所有平面图的外圈都使用同一种折角样式：顶面格保持方形，外圈角块是轻微
  平行四边形，棱块是轻微梯形，外圈只伸出半格。平面图统一归一化到“黄顶绿前”，
  公式里带整体旋转导致顶面不是黄色时，会自动转回黄色顶面再画。
- 三阶 / 二阶 / 四阶的 OLL 与 4x4 OLL Parity 状态卡片仍使用 OLL 状态图：
  顶面黄色/深灰块，侧面只画朝向侧面的黄色块；侧面块沿顶面边与中心格同宽并
  紧贴，向外只伸出半格，角块做成轻微平行四边形、棱块做成轻微梯形。

## 其他项目缩略图

- 其他项目也按“只显示当前步骤相关块、已还原部分保持原色”的原则套用 cubing.js
  stickering：二阶 OLL / PBL / CLL / EG 等使用 OLL / PBL / OCLL，四阶
  OLL / PLL Parity 使用 OLL / PLL，五阶 / 六阶 L2C 使用 L2C，五魔方
  CO / CP / EO / EP / PLL 使用 OCLL / CPLL / EOLL / EPLL / PLL。
  没有对应 cubing.js 预设的分类（如 L2E、金字塔、斜转）保持原来的 3D 显示；
  SQ1 使用自绘 3D 缩略图。
  二阶 CLL / EG1 / EG2 的状态卡片只显示黄色块；四阶 `PLL Parity` 的状态卡片
  全部改成平面图，不再混用 3D。

## SQ1 缩略图

- SQ1 状态卡片使用自绘 3D 缩略图：去掉中间层（EQUATOR）贴纸；
  CO / EO / OBL 改用上下层分开的平面黑白图：左顶层、右底层，黑 = 黄色面
  朝外（axial u）、白 = 白色面朝外（d），能直接看出每层哪些块需要调整；
  平面图会按顶层角块的方向转正（方块四角落在 45°），两层共用同一转角，
  保留上下层相对朝向；CO 只画角块、不画棱块；这类卡片不受“顶面：黑”切换影响。
  其余分类的面色为红 #E2231A / 绿 #00A651 / 橙 #F58220 / 蓝 #1E3F94，
  贴纸缝和描边都比原来更细；CP / EP / PBL / Parity 保留顶底层完整颜色；
  CS 只显示灰色形状，CSP 保留颜色。中层块体与上下层同色（完整配色用
  黑色塑料、形状用侧面灰），不会单独出现深色带。
- 缩略图上下层厚度比原来薄 20%（0.8 → 0.64），中层保持 0.4 不变；
  投影后再把高度 +10%、宽度 −5%（`HEIGHT_RATIO` / `WIDTH_RATIO`），
  整体宽度相对最初版本累计收窄约 44%，最后缩放到卡片白框内，
  所有 SQ1 状态大小一致。
- 公式库顶部有 SQ1 的“顶面：黄 / 黑”切换，黑顶只覆盖 3D 缩略图的顶面，
  侧面颜色保留，不影响 CO / EO / OBL 的黑白平面图。
  状态由 cubing.js 的 square1 KPuzzle 计算，和 3D 演示保持一致。

## LSLL

- LSLL 分类：两步（ZBLS + ZBLL/PLL）与一步（全量 579,368 条最优解）可切换；
  两种模式都先按 41 个大类展示 LS 状态卡片。一步点进去按需加载该大类，
  两步则依次展示 ZBLS 状态和全部 493 个 ZBLL/PLL 名称，点击名称跳到
  ZBLL / PLL 分类查看公式。
- LSLL 状态缩略图统一使用平面色块：仅顶面需要还原、底层不动时画成
  顶面 3x3 + 周围一圈；涉及底层时按等距投影折成 3D 立方体，不另做美术设计。
  2x2 / 3x3 / 4x4 / 6x6 / 7x7 的普通 case 也按同一规则：只有顶层未还原时换成平面图，
  其余保持 3D；二阶 PBL / EG 保持 3D，5x5 保持 3D。平面图每小格固定 10px，
  并按阶数一一对应；3D 缩略图整体尺寸按 (阶数 + 2) × 10px 再增加 15px，
  空白框按缩略图实际高度收缩。
