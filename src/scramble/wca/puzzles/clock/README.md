# Clock 本地生成器（M2）

## 文件

| 文件 | 内容 |
|---|---|
| `clock.js` | 14 表盘状态、18 个动作向量、Z/12Z 线性代数、WCA 记号 |
| `provider.js` | 随机状态 -> 动作表示 -> 打乱文本 |

## 模型

Clock 的 14 个独立表盘可以看作 Z/12Z 上的线性空间：

- 动作：UR/DR/DL/UL/U/R/D/L/ALL，正面/背面各一套，共 18 个向量；
- 随机状态：14 个表盘各取 0..11；
- 求解：在 18 个动作里选一组基，解 14 元线性方程组（mod 12），
  取非零动作最少的一组表示；
- 输出：正面动作 / `y2` / 背面动作 / 随机引脚（UR/DR/DL/UL）。

`solveClock(state)` 返回的是「复原态 -> state」的动作序列，不是把 state
解回复原的序列；两者在生成打乱时容易混淆。

## 规则

- 4b3 要求状态至少 2 步可解；距离 <2 会重抽。
- 引脚在最后随机选择，符合 WCA Clock 打乱格式。
- 生成后从复原态复算，必须与随机状态完全一致。

## 实测

- 表：无。
- 单次生成：约 50–150 ms（14 元线性方程组）。
- 打乱文本通常 9–14 个非零动作，另有 `y2` 和引脚。

## 限制

- 求解器每个随机状态都跑一次子集搜索（C(18,14)=3060 组）；
  M5 可以考虑预计算独立基或缓存。
- 输出是线性表示，不保证是步数最少的最优解；只要状态距离满足 4b3 即可。
