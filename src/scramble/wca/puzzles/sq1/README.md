# Square-1 本地求解器（M2）

## 文件

| 文件 | 内容 |
|---|---|
| `sq1.js` | Square-1 块级状态、形状表、排列表、两阶段搜索、记号 |
| `provider.js` | 随机状态 -> 搜索 -> 打乱文本 -> 逆序列复算 |

## 结构

- **形状表**：7,536 个形状索引，BFS 求回到可做 `/` 形状的距离。
- **排列表**：8 角 + 8 棱的排列距离，共 80,640 个状态。
- **两阶段搜索**：
  1. Phase 1：回到可做 `/` 的形状；
  2. Phase 2：复原角/棱排列与中层。
- 随机状态由形状索引 + 角/棱排列 + 中层组成，均匀采样后搜索。

## 记号

- `(x,y)`：顶层 x 个 30°、底层 y 个 30°；
- `/`：中层翻转；
- 生成器输出的序列是「复原态 -> 随机状态」，由搜索解取逆得到；
- provider 用状态模拟器应用打乱，再应用逆序列，必须回到复原态。

## 规则

- 4b3d 要求至少 11 步；
- 输出至少 11 个 `/`；
- 打乱状态允许直接做 `/`（WCA 4b3d / 12c）；
- `notation.js` 的 `requireSlash` 会检查 `/` 是否存在。

## 实测

- 表构建：约 0.25–0.5 s（Node）/ 0.5–1 s（浏览器）。
- 单次生成：约 20–80 ms。
- 打乱通常 11–14 个 `/`。

## 限制

- 搜索使用递归，深度较大时依赖 V8 栈；当前随机状态测试稳定。
- 输出长度分布可能与 TNoodle 不同；M5 再做 1 万样本统计。
- 算法参考公开的两阶段求解思路，代码为本地重写；分发前仍需做许可审计。
